カスタマイズ可能なデータ形式を持つシンプルなウェブベースのメモアプリケーション。

以下の日本語版 README マークダウンチャンクを提供します。

## 機能
- カスタマイズ可能なデータフィールドを使ってメモを保存できます
- クラウドストレージ API を使って複数のデバイスで同期できます
- GPS 位置情報の追跡をサポートしています
- メモを CSV ファイルとしてダウンロードできます

## 要件
このアプリケーションは、任意の最新のウェブブラウザで動作します。追加のソフトウェアは必要ありません。

## 使用方法
1. [webmemofmt](https://code4fukui.github.io/webmemo/)のウェブサイトをウェブブラウザで開きます。
2. "+ new memo"ボタンをクリックして新しいメモを作成します。
3. カスタマイズ可能なデータフィールドを使用してメモの詳細を入力します。
4. メモは自動的に保存され、クラウドストレージと同期されます。
5. "download CSV"ボタンをクリックして、すべてのメモをCSVファイルとしてエクスポートします。

## データ/API
このアプリケーションは、[JSON Storage API](https://json-storage.sabae.cc/) を使用して、デバイス間でメモを同期します。
